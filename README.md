# Hyprkil

Hyprkill is my personal hyprland rice, I had never use linux before and wanted to go all straight in, so in my first weeks I started using hyprland [Early Rice]([https://choosealicense.com/licenses/mit/](https://www.reddit.com/r/unixporn/comments/1kte8ka/hyprland_hyprkill/?utm_source=share&utm_medium=web3x&utm_name=web3xcss&utm_term=1&utm_content=share_button)).
I have been adding a lot across this year learning about linux, and I though it would be cool if more people used my rice

## Installation

1.- Have a clean Arch installation

2.- Clone this repo and grant permissions to the install.sh
```bash
git clone https://github.com/ramn100dev/hyprkill
chmod +x install.sh
```
3.- Run the install.sh script
```bash
./install.sh
```
